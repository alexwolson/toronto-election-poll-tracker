# City Hall Watcher assets

These assets come from the user-supplied `chw-design-system/assets/logos/` export:

- `chw-mark-64.png`: 64px publication mark, displayed at 30px in the masthead and footer.
- `chw-favicon-32.png`: 32px favicon.

The original pixels are preserved. Each PNG embeds its source origin as Impeccable
provenance metadata. The adjacent publication name is live text, as required by the
CHW design system.
